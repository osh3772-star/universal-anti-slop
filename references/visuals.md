# Graphics, illustrations, generated images and videos

## Detect
- Random gradients, flare, bloom, overly shiny texture, muddy materials and generic cinematic treatment.
- No clear focal point; competing highlights; repeated decorative motifs; illegible text.
- Inconsistent character or product identity across frames; off-model clothing/proportions/colors.
- Incoherent lighting, broken visual continuity or motion that exists only to impress.
- Unnecessary detail on icons, engineering diagrams or functional illustrations.
- User-requested imagery replaced with emoji, arbitrary icon packs, simplistic shape placeholders, or an asset list without actual image files.

## Revise
- Identify the viewing context and focal point; set intended visual hierarchy.
- Use a deliberate, referenced visual language with typography, color and composition appropriate to use.
- Preserve required identity, labels, existing images, transparency, aspect ratio, color profile and resolution.
- For sprite/animation frames, keep alignment and seamless timing where required; do not replace a real reference with a thematically similar but different asset.
- Do not claim to have fixed pixel-level problems without inspecting rendered assets.
- When the deliverable needs original image assets, follow `asset-first.md`: specify a coherent visual direction, produce the files with available image/vector tools, integrate them, then inspect the rendered result.

## Verify
Inspect actual outputs at target scale. Confirm resolution, transparency, clipping, alignment, text legibility, export format and asset count where applicable.
