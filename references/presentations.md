# Presentations / PPT / Keynote / Google Slides

## Detect
- Same title+3 cards+icon arrangement on every slide, independent of what is being communicated.
- Title says a topic but not the slide's actual takeaway; dense paragraphs read aloud.
- Generic illustrations and repeated stock icons filling empty space.
- Random purple gradients, shadows, rounded cards and decorative charts without data.
- Tiny labels, weak contrast, overlapping text, inconsistent margins, or graphs with missing units.
- Unnecessary transitions and animations that consume attention.
- Fabricated charts, numbers, source notes or screenshots.

## Revise
- Give each slide one primary job: context, evidence, comparison, mechanism, decision, or transition.
- Choose layout to match content: comparison table for tradeoffs, diagram for flow, chart for trends, image for physical examples, narrative for argument.
- Repeat a coherent design system (type, spacing, alignment) without repeating the same composition.
- Use few well-chosen visuals instead of many filler icons. Prefer actual data and screenshots where authorized.
- If a slide needs an illustration, process diagram, character, or distinctive visual, apply `asset-first.md`: create and insert a purpose-built asset instead of filling space with emoji, generic icons, or decorative shapes. Do not invent evidence or use generated illustrations as factual screenshots.
- Make evidence, date, units, and source legible. Keep original slide numbers/required team info intact.
- In translation slide decks, distinguish original / draft / edited / reason using clear consistent labels; never recolor entire unchanged sentences as if edited.

## Verify
Render every slide if possible. Inspect text clipping, overlapping, font substitution, contrast, data accuracy and relative emphasis. If a visual preview is not available, say no visual check was performed.
