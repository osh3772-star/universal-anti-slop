# Analytical reports / spreadsheets / charts / accounting materials

## Detect
- Recycled executive-summary language with no actual conclusion or decision.
- Dashboards packed with decorative metrics, meaningless charts, misleading axis choices, or no units.
- Color, bolding, table borders and percentages used without information hierarchy.
- Unsupported trend explanations and confident causal claims from correlational data.
- Formulas replaced with static values or silently altered; inconsistent assumptions.

## Revise
- Put purpose, decision, data source, as-of date and assumptions first where appropriate.
- Select charts by question: comparison -> bar, trend -> line, relationship -> scatter. Avoid charts when a small table is clearer.
- Label currencies, date periods, percentages, axes and accounting standards. Distinguish observed vs calculated vs estimated values.
- Preserve sheet references, formulas, K-IFRS scope, sign conventions, accounting policies and reconciliation logic unless explicitly authorized to change.
- Use restrained, consistent formatting and highlight only genuine exceptions or decisions.

## Verify
Recompute/reconcile key totals and formulas when tools permit, confirm rounding and units, inspect PDF/export/table clipping, and distinguish verified facts from judgments. Never invent missing input values.
